# Mobile Status Update
## Recent and current progress
Currently, about 25% of the sensors are transmitting data. The team has prepared the plan for daisy-chaining additional sensors, and the air quality sensor is successfully sending data to the database.

On the mobile side, the core screens have been built — including the Dashboard, Insights, and Leaderboard, along with supporting fragments such as About, Settings, Notifications, and Contact Support. Live notifications, sensor readings, and user details are now stored in the database.

## Financial
### Expenditures since previous report
On the software side, the only cost incurred so far has been $25 for creating a Google Play Developer Account to enable publishing of the mobile application.

On the hardware side, the project has spent $175.31. This covers the purchase of sensors, Qwiic cables, the 40-pin header and Qwiic connector soldered onto the custom-made PCBs, as well as the parts used to attach the PCB to the Raspberry Pi and the Sense HAT.

In total, the project’s expenditure to date amounts to $200.31, with no other costs incurred beyond these software and hardware expenses.
